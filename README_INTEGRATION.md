# Intégration du dossier public *Profondeur*

**Édition : 5 novembre 2026 — version 1.4**  
**Crédit artistique public :** *Profondeur*, une création de **Réjean McCormick**.

Cette archive regroupe des documents Markdown dans `docs/oeuvre/`. Ils forment une proposition de présentation artistique institutionnelle, indépendante d'un déploiement logiciel particulier. Le dépôt cible n'a pas été modifié automatiquement.

## Installation dans un dépôt GitHub

1. Extraire le dossier `docs/oeuvre/` à la racine du dépôt de présentation choisi.
2. Ajouter un lien dans son README principal :

   ```markdown
   [Profondeur — documentation artistique](docs/oeuvre/README.md)
   ```
3. Relire la [notice institutionnelle](docs/oeuvre/15_NOTICE_INSTITUTIONNELLE.md), la [déclaration d'intention](docs/oeuvre/02_DECLARATION_D_INTENTION.md) et les statuts techniques avant une publication officielle.
4. Lorsque les nouvelles éditions de l'encyclopédie sont publiées, mettre à jour `08_ETAT_DES_REALISATIONS.md` avec leur URL, version et preuves vérifiables.
5. Pour les éléments relatifs à Wikipédia, **renseigner les URL de révision, dates et règles applicables** avant de présenter une opération éditoriale historique comme fait confirmé.
6. Vérifier les droits de reproduction, les licences logicielles et documentaires et les obligations de transparence auprès des organismes de publication.

## Règles de présentation

Lire en priorité [18 — La signature comme œuvre](docs/oeuvre/18_LA_SIGNATURE_COMME_OEUVRE_ET_EFFACEMENT.md), puis [17 — Noms, signatures et périmètre](docs/oeuvre/17_NOMS_SIGNATURES_ET_PERIMETRE.md) : cette charte fait autorité sur les noms publics dans cette édition.


- **Titre de l'œuvre :** *Profondeur*.
- **Crédit artistique public :** Réjean McCormick.
- **Personnage d'auteur dans l'œuvre :** Gustave Leblanc ; marque MÉCANISMES ABSTRAITS, signée « par Gustave ».
- **Couche technique :** réalisations et projets associés dans leurs états respectifs, sans prétendre que tous sont unifiés ou certifiés.
- **Couche esthétique :** mise en abyme, art des correspondances, inspiration, harmonie des langues et question de l'auteur.
- **Bibliographie :** filiations et débats historiques, jamais des approbations attribuées aux personnes citées.

Aucune donnée personnelle privée n'est nécessaire à l'interprétation ou à la publication de ces documents. Les obligations administratives éventuelles relatives à une signature artistique et les vérifications éditoriales doivent être traitées séparément.
